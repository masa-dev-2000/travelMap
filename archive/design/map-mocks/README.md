# TravelMap 地図UI比較モック

10案を同じサンプル記録で操作・比較する独立した静的ページ。既存アプリへの統合・本番公開は行っていません。

## 起動

このディレクトリで実行します。

```sh
python -m http.server 8794 --bind 127.0.0.1
```

http://127.0.0.1:8794/ を開きます。`?v=6` のように案を直接指定できます。

## 操作

- 上部の選択欄・左右矢印・「10案」で案を切り替えます。
- 「スマホ」はPC内で幅390pxのプレビュー、「画面に合わせる」は実際の画面幅に追従します。狭い画面ではPC指定時も画面内に収めます。
- 地図を移動・拡大縮小し、ピンから詳細を開けます。案の切り替えでは地図位置と選択を保持します。
- 小型メニューから記録・収支・旅程・入力を操作できます。02は検索、07は日付、08は訪問順、09はピンの小型ポップアップが入口です。
- 「公開用」は公開対象のサンプル8件だけを表示し、収支・入力を隠します。
- 保存・公開設定の変更はページ内メモリだけ。再読み込みで初期状態に戻ります。

## データ・参考UI

12件の記録は架空です。バックアップ・実データ・API・認証への接続はありません。地図タイルはOpenStreetMapから取得するためインターネット接続が必要です。

「参考UI」から取得画像と出典を確認できます（2026-09-09取得、ローカル検討用）。

| 参考 | URL | 対応案 |
| --- | --- | --- |
| OpenStreetMap | https://www.openstreetmap.org/ | 01、09 |
| Google Maps | https://www.google.com/maps | 02、04 |
| Apple Maps | https://maps.apple.com/ | 03、06 |
| Mapy.com | https://mapy.com/ | 05 |
| Windy | https://www.windy.com/ | 07、10 |
| komoot | https://www.komoot.com/plan | 08 |

Googleの画像は検索・分類バー部分のみを切り出し、個人の履歴・アカウント表示を除外しています。06の下部ドックと10の扇状メニューは、参考サイトの操作配置をTravelMap向けに再構成したものです。
